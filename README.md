# Parcel - This app using `Parcel` as its bundler. Parcel is not only a bundler but it does lot of other stuffs.

- Provides Development build
- Provides Local Server
- Does Tree Shaking - remove unused code
- Does code splitting
- Provides different builds for development and production
- Uses HMR (Hot Module Replacement) using File watching algorithm
- Does caching to make build faster
- Does Image optimization
- Does code compression
and more (https://parceljs.org/)
